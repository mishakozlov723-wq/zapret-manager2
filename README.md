# Zapret Manager

Независимый менеджер для [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Основан на работах Flowseal и bol-van.

## Как устроено
Главная страница ведёт по шагам, и следующий шаг закрыт, пока не выполнен предыдущий:
1. **Проверка компьютера.** Только чтение: старая служба `zapret`, служба менеджера, winws.exe вне служб, другие обходы (GoodbyeDPI и др.), VPN, прокси, TCP timestamps, DNS для YouTube и Discord.
2. **Старый Zapret.** Отключение распознанной службы Flowseal (файлы остаются, тип запуска можно вернуть) или закрытие winws, запущенного вручную.
3. **Скачать Zapret.** Официальный ZIP релиза, проверка размера и SHA-256 из GitHub API. Если этот релиз уже скачан и проверен, повторно не качается.
4. **Стратегия.** Плашка на каждую стратегию. Работает всегда одна служба `ZapretManagerWinws`, поэтому стратегии не накладываются: переключение заменяет команду этой службы.

Перед запуском службы, как и в официальном `service.bat`, включаются TCP timestamps.

## Если YouTube не работает ни с одной стратегией
Проверьте предупреждение о DNS на главной. Если провайдер подменяет DNS, Zapret помочь не может: нужен зашифрованный DNS (DoH) в Windows или в браузере. VPN и другие обходы нужно закрыть.

## Фирменный установщик

Скачиваемый файл: `dist/Zapret-Manager-Setup.exe`. Это самостоятельная WPF-оболочка со встроенным NSIS-пакетом, шрифтами Manrope/Poppins и иконками менеджера. Пользователю не требуется устанавливать .NET. При отсутствии WebView2 штатный пакет загружает его из Microsoft; для этого нужен интернет.

- `npm run build:installer` — упаковать уже собранный менеджер, не перезаписывая работающий exe, и собрать оболочку (нужен .NET SDK 8+).
- `npm run build:release` — полная сборка менеджера, NSIS и оболочки. Перед ней закройте окно менеджера, службу не отключайте.
- `dotnet run --project installer/Setup.csproj -- --self-test installer-verification` — проверки путей, встроенных ресурсов и настоящих окон WPF с сохранением снимков. NSIS при этих проверках не запускается.

Установка доступна текущему пользователю в доступную ему папку. При повторной установке используется прежнее расположение; перенос требует удаления через Windows без очистки данных. Открытый менеджер нужно закрыть вручную — установщик не останавливает службу. Процент установки не выдумывается: пока работает NSIS, показывается неопределённый индикатор. Завершение подтверждается кодом процесса, наличием exe/деинсталлятора и записью Windows.

Исходники оболочки: `installer/`. Проверка на чистой Windows без WebView2 и полноценная установка/удаление должны выполняться в отдельной тестовой учётной записи или виртуальной машине перед публикацией. Пакет пока не подписан цифровой подписью; Windows может показывать предупреждение SmartScreen.

## Сборка и тесты
`npm run build` или `cargo test` в `src-tauri`. Тестам с реальным архивом нужна переменная `ZAPRET_TEST_ZIP` (путь к `release.zip`). Операции со службами требуют прав администратора (UAC).
