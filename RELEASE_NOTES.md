## Что нового в 0.3.6

- **Подключение больше не обращается к GitHub.** Проверка архива идёт по сохранённой контрольной сумме, поэтому лимит GitHub и ошибка 504 подключению не мешают.
- **Самовосстановление.** Если распаковка прервалась или антивирус удалил winws.exe, при нажатии «Подключить» менеджер сам удалит сломанную копию и распакует заново. Если антивирус снова удалит файл — подскажем добавить папку в исключения.
- **Удаление старых версий.** На странице «Версии» есть кнопка «Удалить старые версии»: отметьте галочками ненужные и удалите. Текущую версию удалить нельзя.
- **Автозапуск запоминается.** «Отключить» больше не сбрасывает «Запуск с Windows»: при следующем подключении автозапуск вернётся сам.
- **Меньше ложных предупреждений о VPN.** Предупреждаем, только когда VPN реально включён, а не просто запущен. Предупреждение можно скрыть кнопкой «Скрыть».
