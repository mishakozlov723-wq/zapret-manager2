Что нового в 0.3.0:
• Если GitHub не отвечает (например, ошибка 504), программа сама пробует ещё раз, а потом показывает таймер до следующей попытки.
• В «О программе» видна версия и есть кнопка «Проверить обновления»: новая версия скачивается и ставится прямо из программы.
• Установщик обновления проверяется по SHA-256 перед запуском.
